Risks and Mitigations

Risk Register

Each risk identified during the pipeline design has a corresponding mitigation captured here and in the decision log.

Risk Mitigation
Rule-pack drift on the Semgrep Registry Local cache at /tmp/semgrep-rules/; snapshot timestamp recorded in decision-log.md
CWE inference miss for a novel rule Deterministic keyword table; CWE-693 fallback for unmatched rules
Future Semgrep severity addition mis-categorized Default to low; mapping documented in decision-log.md
Findings ordering changes between runs Preserve Semgrep emission order; no re-sorting
Pinned Semgrep version 1.163.0 ages out Re-run requires an explicit pin bump documented in the decision log

How the Team Onboards

Re-Running Config B

Three commands reproduce the pipeline end-to-end. Re-runs against the same rule-pack snapshot produce a bit-for-bit identical findings-config-b.json.

1.
Install Semgrep 1.163.0 via pip
2.
Cache 3 packs to /tmp/semgrep-rules/
3.
Execute scan with --metrics=off
  1. pip install semgrep==1.163.0
  2. mkdir -p /tmp/semgrep-rules && curl -fSL https://semgrep.dev/c/p/security-audit -o /tmp/semgrep-rules/security-audit.yml && curl -fSL https://semgrep.dev/c/p/secrets -o /tmp/semgrep-rules/secrets.yml && curl -fSL https://semgrep.dev/c/p/owasp -o /tmp/semgrep-rules/owasp.yml
  3. semgrep scan --config=/tmp/semgrep-rules --sarif -o results-semgrep.sarif --metrics=off .
