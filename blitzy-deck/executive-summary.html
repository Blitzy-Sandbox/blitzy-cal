Reasoning and pattern layers

Layer 1 — Blitzy native

tool: blitzy

Context-aware reasoning over code, configuration, and architecture — fail-open logic, configuration defaults, cross-file key reuse.

Layer 2 — Semgrep

tool: semgrep

Curated pattern matching — committed secrets, CI/CD injection, container misconfiguration, crypto anti-patterns, insecure transport.

Dataflow and dependency layers

Layer 3 — Joern

tool: joern

Code Property Graph and taint queries — command injection CWE-78, SQL injection via ORM CWE-89, authorization bypass.

Layer 4 — OSV-Scanner

tool: osv-scanner

Lockfile matching against the OSV database — known CVEs in declared npm dependencies from the single yarn.lock.

Risks and mitigations

Fail-open authorization
Blocked users could slip through on error; fail closed instead.
Reused secret key
One key spans many purposes; separate and rotate per use.
Weak hashing and CSP
Legacy SHA-1 and inline scripts; modernize crypto and policy.
Verification bypass
Bot check skipped when unset; require it in production.
