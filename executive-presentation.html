SECTION THREE

Output Schema

Algorithm

Normalization Flow

sequenceDiagram
  participant SARIF
  participant JSON
  participant Normalizer
  participant Output
  SARIF->>Normalizer: parseSarif()
  JSON->>Normalizer: parseSnyk()
  Normalizer->>Normalizer: normalize fields
  Normalizer->>Output: JSON.stringify(merged)

Each finding receives its source-prefix tag and 200-character truncation before final merge.

Deliverable shape

Output Format

5 Schema fields per finding
1 Line in findings-config-h.json
UTF-8 Encoding, no BOM
[{"file":"<relative path>","line":<integer>,"severity":"<critical|high|medium|low>","cwe":"<CWE-ID>","description":"<max 200 chars>"}]

Five-field minified JSON guarantees byte-comparable diffs across the Config A through H tool comparison.
