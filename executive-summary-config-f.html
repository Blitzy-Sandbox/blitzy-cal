Existing · .github/workflows/security-audit.yml

  • yarn npm audit --all --recursive — informational phase
  • --severity critical — build-failing phase
  • One accepted exception: npmAuditIgnoreAdvisories: ["1113407"] for fast-xml-parser 4.4.1
  • Source: Yarn audit database

Config F · OSV-Scanner

  • Aggregates GHSA, RustSec, PyPA, Go vuln DB, OSV.dev
  • Read-only · no policy enforcement (artifact-only)
  • Surfaces findings beyond the Yarn audit database
  • Source: osv.dev federated index

Both posture gates run independently · Config F is a comparison artifact, not a policy gate.

  3. Normalize: re-run the inline jq/python pipeline documented in decisions-config-f.md
  4. Verify: cat findings-config-f.json | wc -l returns 1

Decisions

Key Decisions Recorded

Install method
Prebuilt linux_amd64 binary from GitHub releases — apt unavailable on Ubuntu 25.10, Go absent.
Severity mapping
CVSS V3 vector → numeric base score → bucket: ≥9 critical, ≥7 high, ≥4 medium.
CWE precedence
affected[].database_specific.cwe_ids[0] → top-level cwe_ids[0] → CVE alias → OSV id.
Deduplication
Collapse aliased records via groups[] — one finding per group. No-op on this corpus.
