Section Five

Continuing Forward

Four steps to reproduce the audit on any developer workstation.

Operational Runbook

How the Team Reproduces This Audit

  1. Install Semgrep CLI with pip install semgrep.
  2. Pre-fetch the three rule packs into /tmp/semgrep-rules/.
  3. Run semgrep scan --config=/tmp/semgrep-rules --sarif -o results-hybrid.sarif --metrics=off .
  4. Merge native findings, then verify wc -l findings-config-c.json returns 1.
