Team Onboarding

How to read, consume, and trust the output
Three artifacts, one source of truth

Consumption guide

Each deliverable has a different audience and a different shape — together they cover machine ingestion, engineering review, and executive narrative.

findings-config-a.json
Single-line minified JSON array. Five fields per finding — file, line, severity, cwe, description. Pipe directly into comparison tooling.
decision-log.md
Markdown table of every non-trivial decision — severity calibration boundaries, CWE selection rationale, and the explicit deviation from "one new file" to three.
executive-summary.html
This deck. Self-contained reveal.js HTML. Open in any modern browser — no local server, no build step, no dependencies beyond the pinned CDNs.

Forward Path

From measurement to mitigation
Where to invest next

Recommended mitigation tracks

Four parallel tracks address the heaviest clusters and unblock the next configuration in the comparison study without touching feature work.

Secrets & cryptography
Replace the default secret-placeholder ARG declarations in the container build, audit keyring rotation hygiene, and confirm constant-time comparisons end-to-end.
Container · keyring · auth
Web boundary hardening
Extend CSP nonce enforcement beyond the login surface, tighten frame ancestors, and audit redirect destinations and image-domain allow-lists.
proxy.ts · CSP · Helmet
Container & CI hardening
Add a non-root USER, pin third-party GitHub actions by commit SHA, and enforce minimum-permission tokens across the fifty-nine workflows.
Dockerfile · workflows · actions
Supply-chain governance
Re-evaluate the fast-xml-parser accepted advisory, cycle pinned resolutions on a cadence, and require change-justification for new patches.
resolutions · advisories · patches
